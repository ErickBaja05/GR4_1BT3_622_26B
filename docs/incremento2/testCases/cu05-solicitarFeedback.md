CU05: Solicitar retroalimentación de hallazgo
•	Identificador: CP-CU05-01
•	Nombre: Solicitud exitosa para el hallazgo de una auditoria.
Precondiciones
•	El hallazgo no posee solicitudes de revisión previas registradas.
Datos de entrada
•	Hallazgo Seleccionado: HLG-001
•	Justificación: “La función requiere múltiples estructuras condicionales para el control de errores de entrada”
Procedimiento
•	El Estudiante consulta el reporte de auditoría del proyecto académico.
•	El Estudiante especifica el hallazgo u observación realizada en la auditoría: "HLG-001 (Complejidad ciclomática alta)".
•	El Estudiante redacta la justificación técnica, duda o argumento de revisión: ""
Resultado Esperado
•	Se verifica que el hallazgo no tiene solicitud previa, se crea la solicitud de retroalimentación para el hallazgo especificado y notifica la solicitud al docente.
•	El Sistema guarda una SolicitudRetroalimentación en estado “PENDIENTE”
•	El Estudiante recibe la confirmación del registro de la solicitud.
